# Rule-language fixture run

Date: 2026-10-11

Purpose: compare the `## Communication` language bullet with the version it replaces, after an agent
wrote English into a Chinese repository document while both the conversation and the document were
Chinese. The change adds one decision boundary: an established file or repository convention wins
over the English default.

## Inputs

- Fixtures and grading: [`../README.md`](../README.md), [`../fixtures/`](../fixtures).
- Baseline: [`../arms/baseline/RULE.md`](../arms/baseline/RULE.md), byte-identical to
  `agents/global-rules.md` lines 201–203 before this change (checked with `diff`).
- Current: [`../arms/current/RULE.md`](../arms/current/RULE.md), the wording applied afterwards.
- Harness samples: fresh DSH subagent per cell, one sample per cell except `L1` (three), allowed
  reads declared in each prompt, commands and edits forbidden. The subagent model is not visible
  from this session and was not recorded; that is a limitation of this run, not a claim about which
  model ran.
- Local tier: `qwen3.8-flash-next iq3-text` through the gateway, three samples per arm, run by
  [`../local-run.py`](../local-run.py). That tier has no file tools, so the fixture text was inlined
  into the prompt (`L1-inline-local`) — a weaker variant, not equivalent to `L1`.
- Language is graded by [`../grade.py`](../grade.py) as `cjk / (cjk + latin letters)` over the
  artifact; no model's own account is used.

## Results

Each line: baseline / current, samples passed.

- **L1 existing Chinese doc** — 0/3 / 3/3. The regression case. Every baseline sample wrote the
  English entry `2026-10-11: Backend upgraded to v9.9.9 …` and named the assigned rule as the reason
  ("use English … for repository documentation", "RULE.md … must be in English even though the
  existing entries are Chinese"); two offered a Chinese translation only as a note. Every current
  sample wrote Chinese and named the new clause ("unless the file or repository sets its own
  convention"). Measured ratio 0.000 / 0.395.
- **L2 no convention** — 1/1 / 1/1. Both arms wrote English in a repository with no prose.
- **L3 literal string** — 1/1 / 1/1. Both kept `"network_timeout": "网络超时"` and wrote the comment
  in English (comment ratio 0.000 both arms; artifact ratio 0.080 / 0.068 from the literal).
- **L4 existing English doc** — 1/1 / 1/1. The control; the convention clause did not push an
  English document elsewhere.
- **L1-inline-local** — 3/3 / 3/3, ratio 0.395 both arms. Non-discriminating: with the Chinese
  fixture inlined, the local tier answered Chinese regardless of the rule, so it neither supports
  nor contradicts the change. The old wording did not keep the local tier in English either.

Void: the first `L2` baseline sample ran an undeclared `ls`; it was discarded under the method rule
and replaced by sample 2 (`L2-new-doc` sample 2 above).

## Contamination and limits

- The subagents carry the deployed `AGENTS.md` in their own context. For the baseline arm that text
  agreed with the assigned file, so the arm cannot by itself separate "followed the file" from
  "followed the loaded rules". For the current arm the loaded text (still the old wording during the
  run) **contradicted** the assigned file, and the arm still produced Chinese 3/3 — so the result is
  conservative in the change's favour rather than flattered by it. The rule file was edited only
  after all harness samples were collected.
- One sample per cell outside `L1`, and three for `L1`: a direction, not a rate. The local tier is
  one model on one prompt shape and cannot be generalised to either weaker models or the
  file-reading path.
